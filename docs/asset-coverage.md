# 分类、装配与储备规划

## 分类与发现

11个主类分别管理环境、医学结构、监测、生活方式、资料、人物、纸材、照护、代码、配乐和拟音。文件类型 `kind` 与内容分类分开；发现层按原件 `source_id` 附加中文别名、对象、主题、叙事用途、动作、视角、媒介、材质与兼容性，原件和精确版本不改写。

先检索名称、同义词与用途；来源记录只用于显式追溯。新素材没有策展标签时仍能按标题和原用途查到，不要求先补齐字段才能创作。新类别与媒介可继续扩展。

## 组合与可观看起点

13组装配和8组事件组合保管的是部件引用与关系，不是固定故事或整场PNG。随库 `tools/preview-engine/index.html` 提供21个可寻址、可拖动时间轴的Canvas样例；`audio.html` 可分别试听12个配乐包和9个拟音包的分轨与变体。网页通过库根本地HTTP服务查看。

本轮新增5个透明纸件：左手接取、右手捏持、双手接取人物、裸露上臂、展开袖带；新增一个接触运行模块。已有门、台历、记录本、标本、寝具与生活物件已组织为可试装组合。

## 成熟度按用途记录

原件登记、静态换底、组合试装、连续动作、完整听感、医学语义及本镜头批准是不同证据。几何和浏览器检查不签发艺术或医学通过。组合样例只覆盖登记的部件、参数与动作；复用时重新看当前镜头。

透明外框不等于视觉尺寸。发现层另存可见内容bounds，原图坐标保留；每个部件使用自己的bounds，不能给试纸套主机bounds。接触点、遮挡与相对比例经实际试装调整，不固定到新故事。

## 本轮已落地与后续扩展

| 能力 | 本轮可取用内容 | 持续扩展的方向 |
| --- | --- | --- |
| 人物互动 | 左右手、接取人物、坐站/伸手原件与姿态小样、手臂与袖带试装 | 当前故事需要的握持、情绪、体型和年龄；单一行走姿态不冒充连续步态 |
| 医学结构 | 总览、切面、同图局部放大与来源明确的视图切换 | 需要连续剖开时准备同视角配准部件；未经配准的外观与切面不能直接叠合 |
| 高频事件 | 报告归档、检查资料、测量、用药、随访与纸件接触 | 新患者任务、不同空间与新动作，不沿用原台词或固定镜头数 |
| 生活方式 | 盘与食物独立放入/夹取，人物与运动鞋，床/枕/被褥组合 | 当前故事的烹饪、完整步态、睡姿和活动变化 |
| 声音 | 情绪中文别名、真实BPM/时长、分轨与拟音变体、独立试听 | 在实际旁白与场景中确定密度、尾音、转折与响度，审听后登记覆盖范围 |

持续补缺按“患者任务→可见事件→所需部件→代表镜头试装→本集复核→值得复用才入库”推进。不按固定数量或复用率填满库存，不让库限制导演探索。
