# 医学科普视频初稿质量基线

这份基线把 11 个系列的返修经验放回创作前端，目标是提高第一版的可观看程度和可返修性。资产库提供可靠的起点，导演仍需为每一集重新决定故事、比例、动作和声音。

## 写分镜前先做的事

1. 先按主题、用途和复用范围查询资产库，实际查看原图、透明边界和样例；不要因为文件名或一张联系表就把素材当成可用医学主体。
2. 把患者任务、误解、要改变的判断和结尾行动写成一条可见事件链。每个镜头都说明在场物件、接触方式、动作结果以及带入下一镜的物件。
3. 先做一个代表镜头和一集完整 animatic。代表镜头验证材质和动作，完整 animatic 验证开场、承接、声音和节奏，二者都通过实际观看后再扩展数量。
4. 透明纸件登记实际 content bounds、接触点、遮挡职责、医学用途、来源/生成回执和拒用理由。大背景只作为纸景，不能用来遮住错误的主体。

## 画面与动作

- 按内容的认知比例和画面重量缩放，不按 PNG 外框统一大小；大脑、器官和人体承担主视觉，试管、药瓶和日历退为辅助物件。
- 每个大型纸片必须有身份和动作职责：被揭开、拿起、夹住、翻面、推入、交接、折叠或收纳。没有动作职责的色块、色带、线段和空白卡片优先删掉。
- 环境、主体、固定件、前景遮挡和接触阴影保持同一种纸剧场媒介。撕边、胶带、图钉、折痕和轻微错位服务于纸件的物理关系，不能让整层持续抖动。
- 做“去文字审片”：暂时隐藏标题、标签和解释文字，仍应能看懂主要对象、关系变化和结果。必要的解剖名称再放回画面。

## 文字与声音

- 旁白稿同时保存正文和 `tts_text`。按完整语境标注多音字、医学术语、数字、单位、缩写和停顿；“看字还清楚”这类风险必须在合成前确定读音。
- 首句和高风险术语先做完整声段小样；固定参考声线、语速、音高和距离感。IndexTTS 是有授权声线时的本地默认，Edge TTS 仅作没有专用声线或明确跳过时的备用。
- 字幕在真实纸景和动作帧上排布，不为文字强行加大色块。逐镜检查首帧、切入帧、接触落点、停留和切出；字幕安全区不等于完整可读性。
- BGM 保留无旁白原声、分轨、可编辑工程、音源依赖和许可；动作拟音只在有明确接触事件时加入。无音乐旁白和最终混音分开审听。

## Progress First 的使用边界

初稿缺少完整素材、动态或听感时，保留候选、诊断和质量债，继续不依赖该缺口的工作。被医学否决的素材不得进入有效渲染；字段缺失、库不可用或审看未完成不会阻断其他阶段，也不能被写成通过或可发布。

经验沉淀格式为“具体失败 → 最早原因 → 前置小样/决策 → 最小返修 → 实际证据与未覆盖项”。通用方法回写工作台与 MAC，疾病事实、品牌、医生形象和声线留在系列/作者档案。
