# 肝脏·肝胆下缘位置揭层连续开合

肝脏外形示意，区分左右叶、胆囊与胆道走向；不表示肝内血管分段、肝功能或病灶。 肝下缘局部位置揭层；不表达肝内切面或分段。 没有肝内实质或门静脉分层，只有肝胆外形与胆管走向；提供下缘位置揭层。

## 取用

```bash
python3 scripts/media_asset_library.py use --root <公共库路径> \
  --project <本集工程路径> --id paper:mac_liver_section_open_close_v1@<revision>
```

本地HTTP打开index.html；renderStudy可直接接入Canvas。section配置保存每个边界、枢轴和原图依据；timing控制打开、保持与关闭。保留图层与窗口共同原点；不能把位置图改名为真实切面。
