# 素材覆盖与复用范围

当前素材按人物任务、结构解释和实际动作管理。当前数量、类别与精确可用版本读取 `catalog/assets.jsonl`、`collections/taxonomy.json` 和实时默认查询 `tools/query_assets.py`；历史问题版本保留来源，不进入默认推荐。

基础类别外覆盖生理过程、病理变化、诊疗操作以及风险与决策沟通等可编辑代码组件；其源码、参数、医学参考和交互样例独立保管。它们属于待审候选，不能由新增或数量推断医学通过。

分类继续沿用素材职责，同时增加医学系统、患者任务、机制与人群映射。全量当前候选均有主题标签；通用人物、纸件和声音不被虚构成某种疾病专用素材。用 `--system`、`--topic`、`--patient-task` 组合发现，具体语义由策展判断。

[医学任务覆盖表](../collections/medical-coverage.json)逐项列出核心科普任务的已有候选与缺口。肾单位滤过、具体装置的吸入教学、胰岛素笔注射、完整急救、儿科照护和康复训练等仍为明确缺口，按真实选题继续补充。候选存在、技术运行、连续动作、听感和医学成熟度分别记录。

## 人物与接触

角色基础姿态槽分别登记站、坐、步行、伸手或角色专用姿态，真实覆盖与当前可用资产以 [人物覆盖表](../collections/character-coverage.json) 和实时运行 `python3 tools/audit_character_coverage.py` 为准。同身份和同身体体量须在原图、共同地面及当前镜头实际核对；槽位、标尺字段不批准姿态质量。

| 角色/任务 | 已准备的动作或姿态 | 复用范围 |
| --- | --- | --- |
| 成年男性 | 双侧步态循环、坐站过程、日常轻扶照护；完整低椅坐姿 | 步态、照护沿同一绿衫红裤身份；固定姿态和可编辑动作分别取用 |
| 成年女性、少女、女童、老年男女、孕妇、男童、少年、年轻成年男性 | 每类同身份八姿态：站稳→屈膝→下降→坐定→触纸→持纸→准备起身→站立持纸 | 完整人物/椅/桌接触单元，源图、人工椅脚点及统一身体标尺成套保管；这些坐站包不包含新步态循环 |
| 老年女性床边休息 | 站床边→床沿坐定→支撑侧卧→枕上休息→回床沿→站稳 | 人物、床、枕头和承托为完整六姿态接触单元 |
| 作者医生 | 私有库的走上前、坐下起身、与患者递接报告 | 作者资产保管在私有工作区；公共库仅保管通用角色 |
| 公共通用医生 | 中国男女医生的站讲解、坐姿问诊、步行关键姿态与伸手 | 供未启用作者医生默认策略的工作区使用 |

同场相近景深先共用场景像素/厘米，再核对头肩、躯干、四肢、椅面、脚底和道具。坐姿头顶低于同体量站姿；完整椅床的外框不当人体标尺。角色动作的首帧真实头顶/鞋底垂直跨度贯穿各状态，同一家具点逐姿态人工确认并绑定原图 SHA 和源矩形，避免按外框独立缩放或混选椅脚点。

男童、孕妇及成年男性的基础坐姿已使用同身份完整低椅替代，旧座高或身体构造有误的精确版本退出推荐。身体段标定、可见头部锚点和地面基准分别保管，校准小腿不能把小腿起点写成头部。

作者档案启用 `default_for_clinician` 时，医生性别别名、`generic`、旧公共医生 ID 和自定义别名均沿作者私有母版解析；缺姿态沿同一母版补齐。作者、患者与家属身份在剧本中分别判断。

## 医学结构

医学结构按总览、同位解释近景和独立简化版三类用途组织；简化图保留关键解剖定位，避免只有泛化轮廓。每类提供两种动作：逐层揭示/原位高亮，以及连续开合或同位关系揭层。

| 结构动作 | 当前支持范围 | 表达范围 |
| --- | --- | --- |
| 逐层揭示与局部高亮 | 独立解剖原层组合 | 图层沿同一坐标出现与强调，保留对应关系 |
| 二维局部剖面开合 | 肾、心、胃、胆囊、胰腺、肺泡、乳腺 | 使用原件对应外层与内部；窗口受对象边界约束，关闭恢复初始主体 |
| 既有横断面展开 | 动脉壁 | 在横断面内连续展开壁层扇区 |
| 局部关系揭层 | 甲状腺、垂体、肺、肝、肠、胰岛、红细胞、踝足、盆腔、头部 | 名称按位置或投影关系；红细胞淡区仍是胞质，盆腔前后投影保留各自职责 |

不同视角的总览与近景通过切镜连接。同位配准可支持二维揭示，三维旋转、手术入路、生理运动与病变定位需要另外的真实素材和医学依据。具体可取用版本见[动作清单](motion-studies.md)，原用途与限制随各包说明。

按观众要理解的关系决定阅读面积和停留：复杂核心使用解释近景或拆分，小尺寸只承载单一轮廓、类别提示或已讲过的归档内容。原尺寸、手机宽、动作极值、落定和邻镜都需实看；近景缩小不能充当简化版。

## 监测、生活与声音

血糖包含短试纸连接、采血接触、采样、读取与按压；袖带包贴合裸露上臂，主机与前臂有台面承托；动态血压包补齐佩戴、固定、静止试测、日夜记录和交回。旧毛衣上套袖带的静态人物与旧记录包退出默认推荐。计数点仅表达记录过程，不表示测量数值或频率。

生活动作有切配、入锅、连续翻动、盛盘，以及同身份步态和轻扶照护。厨房台面、刀板、食材、锅具与餐盘分别保管，需要独立运动的部件按各自 bounds 与接触点试装。

配乐与拟音可从[声音入口](../tools/preview-engine/audio.html)及 `collections/audio.json` 选择分轨和变体，包含覆盖旁白下对比与多类动作拟音；原声、旁白混音和本集最终音轨分别实际审听，未听范围保持待审。格式、波形与无削波只证明技术属性。

## 发现、取用与当前镜头

按中文对象、动作、角色和用途查询。例如 `query_assets.py --category motion --character-role 老年男性 --action 坐站过渡` 返回角色动作；普通 `--character-role ... --pose ...` 保持静态覆盖表的精确选择。先看原件，再真实 use，回读版本、载荷、bounds、registration 和 human_scale，最后按本集景别试装。

装配与事件套件定义在 `collections/assemblies.json` 与 `collections/event-kits.json`，提供可重组部件和接触起点；[动作入口](../tools/preview-engine/motion.html)直接读取当前可播放包。完整人物/椅床接触单元按说明整体使用，可拆道具保留独立原件。源码、原件、静态换底、组合、动作、听感、医学及当前镜头分别记录证据。

新素材或动作更新不自动修改历史工程；逐集的真实绘制、清单、音轨、渲染和审看片由原制作负责人落实。库升级也不静默替换旧片的精确版本。新故事的具体朝向、情绪、动作和接触关系仍由导演按需要适配或新创，不按库存数量限制故事。
