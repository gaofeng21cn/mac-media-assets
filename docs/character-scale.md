# 人物原图标尺

## 共同尺度的实际试装

2026-10-24 已对12个角色49个基础姿态完成原图标定及真实query→use→manifest→SHA回读。这证明标尺可传递，不代表49个姿态质量通过。同密度、同地面试装发现男童与孕妇旧坐姿座高及身体构造不合适；现已与成年男性坐姿一起替换为新完整低椅，公共目录、coverage、身份基线及精确尺度注解均已接入，再次真实取用通过。必需槽当前49 registered/49 available/0缺标定。其余比例疑点及各场景仍须实际核对，不从覆盖计数批准。

标定端点与摆放锚点分开。头部标定的to是下巴，不是脚底；排景显式读取registration.anchors.feet/seat。相同头部密度不能修复原件的长躯干、长小腿或高座面；同场复核站高、坐高、座高和真实承托，结构错误须换正确原件。

角色设计身高与图片像素必须共同登记。`collections/character-scale.json` 是绑定精确素材版本的策展注解；query 返回 `human_scale`，工作台 use 将该注解复制进项目 manifest，并返回 `human_scale_readback`。原始内容寻址包不改写，项目保留所用注解快照。

标定记录包括设计身高、明确的人物身份家族、姿态、原图宽高、载荷 SHA256、原图归一化的两个身体标定点、对应的设计长度和依据。它与打印 DPI 类似，但量的是图中身体，不是纸张或透明图片外框。

原图像素/厘米 = 两身体标定点的像素距离 ÷ 对应厘米数。场景统一选择像素/厘米，素材等比缩放 = 场景像素/厘米 ÷ 原图像素/厘米。例如原图880像素对应110厘米，密度为8像素/厘米；场景用3像素/厘米，整件按37.5%缩放，接触锚点一起变换。

站姿可以头顶与脚底标定；坐姿使用与同身份站姿对应的身体段/母版配准；躺姿使用可确认的体轴或身体段。床椅和遮挡物不充当人体长度。透视较强、端点被遮挡或同身份头身比失真的原件应补姿态、补标定或改镜头。

同场相近景深的人物共享场景密度。相机共同变换全景，景深差作用于人物及其接触组；不为填满版面给每个人独立缩放。物理尺度成立后，还要检查地面、椅面、床面、头肩、躯干、接触、遮挡及手机宽可读性。

坐站动作同时配准身体与椅子：臀部确实被座面承托，腿部与脚底落在可信地面，不能从椅子外框猜显示宽度。多帧包先明确锚点来自整张原图还是裁切帧；帧内归一化点(u,v)在裁切区(left,top,width,height)中对应原图像素(left+u×width,top+v×height)，转回同一原图坐标后再与身体标定共同缩放。混用这两种坐标会让标定数值正确但接触错误。

`tools/build_character_scale_index.py` 只准备设计身高候选并保留已有精确版本标定。按角色填入的数值标为 `proposed_design_assumption`，姿态标定为 pending；不可据此宣布已具备自动排景。`tools/audit_character_coverage.py` 分别显示登记槽位和缺少尺度标定的槽位。字段完整、哈希通过与实际画面通过分别记录。
