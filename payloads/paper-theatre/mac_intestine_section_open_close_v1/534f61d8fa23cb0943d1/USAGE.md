# 肠道·结肠内小肠位置揭示连续开合

正面肠道关系示意：结肠构成外围，上行结肠在画面左，小肠盘曲于内；直肠向下。示意层数与曲数不代表真实长度。 外围结肠内的小肠位置揭示；不是肠壁切开。 只有肠道正面位置图，没有肠壁或肠腔层；提供同位的小肠位置揭示。

## 取用

```bash
python3 scripts/media_asset_library.py use --root <公共库路径> \
  --project <本集工程路径> --id paper:mac_intestine_section_open_close_v1@<revision>
```

本地HTTP打开index.html；renderStudy可直接接入Canvas。section配置保存每个边界、枢轴和原图依据；timing控制打开、保持与关闭。保留图层与窗口共同原点；不能把位置图改名为真实切面。
