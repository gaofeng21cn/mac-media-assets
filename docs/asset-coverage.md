# 素材覆盖与复用范围

当前素材按人物任务、结构解释和实际动作管理。数量与精确当前版本读取 catalog 和默认查询；历史问题版本保留来源，不进入默认推荐。

## 人物与接触

12类角色的49个基础姿态槽分别登记站、坐、步行、伸手或角色专用姿态，真实覆盖、锚点、原图身体标尺与可用状态见 [覆盖报告](character-coverage.json)。同身份和同身体体量须在原图、共同地面及当前镜头实际核对；槽位、标尺字段不批准姿态质量。

| 角色/任务 | 已准备的动作或姿态 | 复用范围 |
| --- | --- | --- |
| 成年男性 | 双侧步态循环、坐站过程、日常轻扶照护；完整低椅坐姿 | 步态、照护沿同一绿衫红裤身份；固定姿态和可编辑动作分别取用 |
| 成年女性、少女、女童、老年男女、孕妇、男童、少年、年轻成年男性 | 每类同身份八姿态：站稳→屈膝→下降→坐定→触纸→持纸→准备起身→站立持纸 | 9套完整人物/椅/桌接触单元，源图、人工椅脚点及统一身体标尺成套保管；这些坐站包不包含新步态循环 |
| 老年女性床边休息 | 站床边→床沿坐定→支撑侧卧→枕上休息→回床沿→站稳 | 人物、床、枕头和承托为完整六姿态接触单元 |
| 作者医生 | 私有库的走上前、坐下起身、与患者递接报告 | 作者资产保管在私有工作区；公共库仅保管通用角色 |
| 公共通用医生 | 中国男女医生的站讲解、坐姿问诊、步行关键姿态与伸手 | 供未启用作者医生默认策略的工作区使用 |

同场相近景深先共用场景像素/厘米，再核对头肩、躯干、四肢、椅面、脚底和道具。坐姿头顶低于同体量站姿；完整椅床的外框不当人体标尺。角色动作的首帧真实头顶/鞋底垂直跨度贯穿各状态，同一家具点逐姿态人工确认并绑定原图SHA和源矩形。按外框独立缩放和自动混选前后椅脚会造成悬坐、等高或家具跳位，本批已修复这两类根因。

男童、孕妇及成年男性的基础坐姿已改为同身份完整低椅替代，旧座高或身体构造有误的精确版本退出推荐。身体段标定、可见头部锚点和地面基准分别保管，校准小腿不能把小腿起点写成头部。

作者档案启用 `default_for_clinician` 时，医生性别别名、`generic`、旧公共医生ID和自定义别名均沿作者私有母版解析；缺姿态沿同一母版补齐。作者、患者与家属身份在剧本中分别判断。

## 医学结构

18类结构均有总览、同位解释近景和独立简化版，当前用途矩阵为18×3；新简化图保留胆囊颈管及头部脑底定位，避免只有泛化轮廓。每类又有两种动作：逐层揭示/原位高亮，以及连续开合或同位关系揭层。

| 结构动作 | 当前支持 | 表达范围 |
| --- | --- | --- |
| 逐层揭示与局部高亮 | 18套，61个独立原层 | 图层沿同一坐标出现与强调，保留对应关系 |
| 二维局部剖面开合 | 肾、心、胃、胆囊、胰腺、肺泡、乳腺7套 | 使用原件对应外层与内部；窗口受对象边界约束，关闭恢复初始主体 |
| 既有横断面展开 | 动脉壁1套 | 在横断面内连续展开壁层扇区 |
| 局部关系揭层 | 甲状腺、垂体、肺、肝、肠、胰岛、红细胞、踝足、盆腔、头部10套 | 名称按位置或投影关系；红细胞淡区仍是胞质，盆腔前后投影保留各自职责 |

不同视角的总览与近景通过切镜连接。同位配准可支持二维揭示，三维旋转、手术入路、生理运动与病变定位需要另外的真实素材和医学依据。具体可取用版本见[动作清单](motion-studies.md)，原用途与限制随各包说明。

按观众要理解的关系决定阅读面积和停留：复杂核心使用解释近景或拆分，小尺寸只承载单一轮廓、类别提示或已讲过的归档内容。原尺寸、手机宽、动作极值、落定和邻镜都需实看；近景缩小不能充当简化版。

## 监测、生活与声音

血糖包含短试纸连接、采血接触、采样、读取与按压；袖带包贴合裸露上臂，主机与前臂有台面承托；动态血压包补齐佩戴、腰侧固定、静止试测、日夜记录和交回。旧毛衣上套袖带的静态人物与旧记录包退出默认推荐。计数点仅表达记录过程，不表示测量数值或频率。

生活动作有切配、入锅、连续翻动、盛盘，以及同身份步态和轻扶照护。厨房台面、刀板、食材、锅具与餐盘分别保管，需要独立运动的部件按各自bounds与接触点试装。

12套配乐与14套拟音可从[声音入口](../tools/preview-engine/audio.html)选择分轨和变体。新增5类动作拟音共15变体，并准备了真实旁白下的比较混音；原声、旁白混音和本集最终音轨分别实际审听，未听范围保持待审。格式、波形与无削波只证明技术属性。

## 发现、取用与当前镜头

按中文对象、动作、角色和用途查询。例如 `query_assets.py --category motion --character-role 老年男性 --action 坐站过渡` 返回角色动作；普通 `--character-role ... --pose ...` 保持静态覆盖表的精确选择。先看原件，再真实use，回读版本、载荷、bounds、registration和human_scale，最后按本集景别试装。

17组装配与14组事件套件提供可重组部件和接触起点；[动作入口](../tools/preview-engine/motion.html)直接读取当前可播放包。完整人物/椅床接触单元按说明整体使用，可拆道具保留独立原件。源码、原件、静态换底、组合、动作、听感、医学及当前镜头分别记录证据。

本批完成的动作和素材不自动修改历史89集工程；逐集的真实绘制、清单、音轨、渲染和审看片由原制作负责人落实。库升级也不静默替换旧片的精确版本。新故事的具体朝向、情绪、动作和接触关系仍由导演按需要适配或新创，不按库存数量限制故事。
