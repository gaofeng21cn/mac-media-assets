# MAC Media Assets · 医学科普纸剧场资产库

这是 [Med Auto Cast（MAC）](https://github.com/gaofeng21cn/med-autocast) 的公开媒体资产库。MAC 安装或准备工作台时会自动获取它；用户只需提供选题和创意，MAC 会先检索并查看合适原件，再决定复用、适配、替换或新创。

## 可复用资产总览
