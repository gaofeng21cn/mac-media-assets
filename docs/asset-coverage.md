# 资产覆盖、复用设计与储备

当前库已完成第一轮常用医学科普储备：123 个可复用版本包、514 个载荷文件，覆盖人物、可重组纸景、纸材固定件、高频器官、检查监测、照护、生活方式、动作、拟音与配乐。医学结构和所有声音仍需当前镜头 Review；静态候选、分层和文件完整性不等于连续动作、医学或发布通过。

## 先储备什么

本轮已完成上述优先级储备。后续只在真实故事暴露缺口时增加更细的肢体层、复杂器官揭示、疾病特异结构和更多情绪/拟音变体；不以固定数量或复用率代替导演判断。

随后补充人物姿态与高频器官系统，在真实故事中校对结构与接触关系。疾病特异结构、复杂手术路径和强烈风格变体按具体导演稿准备，不用预制数量替代医学与创意判断。没有匹配素材时 MAC 继续新创，不等待整类库存补满，也不设复用率。

## 素材准备由动作倒推

先写“它要怎样表演”，再决定交付的部件。血糖仪需要试纸插入就分别生成主机与试纸；药瓶需要开盖就分别生成瓶身与瓶盖；人物需要触碰仪器就分别准备仪器和能承担接触的人物姿态。多个可独立动作不能被烘焙在一张PNG里。

每个部件保存原件、来源/提示/生成回执、实际内容边界、枢轴、接触点、朝向、用途和失败边界。装配包另外保存部件之间的相对关系、可移动范围和遮挡意图；尺度根据可见内容与画面重量调整，不统一图片外框，也不把参考参数变成固定构图。

生成后看浅色、深色和彩色底，区分真实alpha与画进图里的棋盘格，检查外光晕、截断、破洞和背景残留。再做实际装配/操作小样，判断接触位置、被遮挡内容和部件比例。检查失败就局部重新准备；不将“请求透明”或文件存在写成通过。

静态查看、装配小样、连续动作、当前镜头医学表达与完整听感分别记范围。机器守文件、身份、版本、哈希、路径和部件完整性；素材是否值得复用由实际观看与模型判断，不能用像素阈值给艺术质量签字。

## 原库存的具体处理

本轮实际查看了原有29个视觉原件及浅/深/彩底合成。六个版本退出默认推荐：双试管与支架、带固定药片/夹子的记录本、视野仪与患者合图、带外围光晕的病床患者、固定全身人物母版、中央大色板诊桌。原因与精确版本在 `collections/curation.json`；原件保留供恢复，重做后建立新版本，不继承通过结论。

三张新准备的整物件合图由分层包替代；一个旧纸夹组件版本也退出推荐。其他完整环境板明确标为后景，医学纸图明确标为单层结构总览，树与房屋合图仅承担完整远景用途。它们的复用价值在整体用途，不宣称内部部件可以拆开运动。

首批分层试制中还实际发现了伪透明棋盘背景，已拒绝并重做。这一失败说明入库前必须查看真实alpha与换底合成；提示词中的“透明PNG”不构成验收。

`catalog/assets.jsonl` 仅持有当前可复用候选，默认查询不返回参考或退出推荐的版本；后者在 `catalog/reference-assets.jsonl`。缺少某个部件不会停止制作，MAC 使用替代素材或新创。当前素材在单集中的Review仍待做，入库和“active”均不等于医学或发布批准。
