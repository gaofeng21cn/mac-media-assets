# 连续备餐：切配、入锅、翻动与盛出

三次刀刃接触后依次出现三片；三片原物入锅、被锅铲连续翻动，最后三片盛入餐盘。

用本机 HTTP 服务打开 index.html，可播放、随机拖动时间轴及换浅/深/彩底。
源码不依赖远程库；runtime.mjs 导出的 renderStudy 接收 Canvas、图像映射、sequence 和秒数。
改镜头时可以换坐标、时长、对象或重做姿态；帧来自完整人物原件，未把人物拆成几何肢体。

道具与食材的日常动作样本；不把动画时长解释成实际加热时间，不推断温度、熟度或营养疗效。手、器具和食材独立可调，接触后才生成切片，转运保持三片身份与数量。

样本无声；不提供听感批准。当前镜头审查在取用后重新进行。
