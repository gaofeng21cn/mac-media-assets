# MAC 媒体资产

人物候选须在同一地面和相近景深做多人/坐站试装：按头肩、躯干与四肢共同校准身体体量，坐姿头顶应明显低于同体量站姿。不能按外框等高或把带椅整件宽度当身高；真实体型、年龄与透视须在场景中成立。单件完整和姿态槽已登记不批准组合比例，换景别后重看；记录实际搭配、地面与适用景别。

本库是 MAC 的独立能力与媒体仓库，根目录在本 Skill 上两级。查询工具是 `../../tools/query_assets.py`，真实文件引用相对于仓库根。从 MAC 调用时，优先使用 MAC 的 `media_asset_library` 工具，按工作区配置发现本库并把选中版本复制到当前项目。

导演准备先按患者问题、视觉锚点和拟承担动作检索，再实际查看原件和动作样例。环境板、透明主体、纸材固定件、组件和声音各有职责；按内容 bounds、认知关系和当前构图决定比例。库里已有的故事、构图、镜头时码和颜色不成为新集模板。

按观看任务区分主焦点、支持组和背景；复杂核心需要解释近景或拆解，小尺寸只承载简单轮廓或已解释归档内容。总览、解释近景与简化版分别记录用途和精确版本关系，不能把缩小详细原件称为简化版；只将真实存在且审看的候选列为可用。人物与椅面、投影、手持物共同试装，并看手机宽预览和动作极值；当前覆盖边界见[尺寸用途与版本覆盖](../../docs/asset-coverage.md#尺寸用途与版本覆盖)。

类别覆盖与储备批次见[覆盖评估](../../docs/asset-coverage.md)，现成候选见[资产清单](../../docs/asset-inventory.md)。实时登记数量读取catalog/sync-readback.json，实际可发现与可取用范围分别查询核对，不沿用说明中的旧总数。优先储备能跨主题独立操作的部件，不按成片截图或整场合图充数。库不完整时继续新创，不为补齐类别或复用率改变故事。

```sh
python3 tools/query_assets.py --query 垂体 --json
python3 tools/query_assets.py --character-role 老年男性 --pose walk --json
python3 tools/audit_character_coverage.py --output docs/character-coverage.json
python3 tools/query_assets.py --kind code_component --json
python3 tools/query_assets.py --kind audio --author-id <当前作者档案ID> --json
```

工作台作者档案启用 `default_for_clinician` 时，所有医生身份、性别别名、generic请求、旧公共医生ID和自定义医生别名都解析当前作者私有姿态；显式公共ID不能绕过该策略。作者姿态缺失返回 `needs_author_pose`，沿同一母版补齐；不换成公共医生，也不复制作者冒充多位医生。公共医生仅供没有启用作者默认策略的工作区。作者私有素材不进入本公共库，实际query、use、源码和画面要共同核对。

人物按具体姿态的原图身体像素/厘米标定，见[人物原图标尺](../../docs/character-scale.md)。设计身高不能代替原图尺寸、SHA和身体段；同场相近景深共享场景像素/厘米，坐卧外框与床椅都不是站立身高。换图后重核标定，未标定候选不得宣称可自动排景。

默认查询每个资产身份只返回当前审定版本；`--all-versions` 或精确 `paper:<ID>@<revision>` 才查看历史。人物查询同时给角色和姿态，空结果是真实缺口。`--id <source_id>` 返回当前版本，不把同名旧修订混进候选。`curation` 是依据原件的模型判断，说明整体背景、单层医学总览、独立物件或可拆部件的实际操作。

人物覆盖以 `collections/character-coverage.json` 和实时覆盖报告为准，已有角色/姿态候选不代表全面覆盖人群与动作；不要用成人缩放代替儿童、老年或孕妇。`character-anchors.json` 记录原图归一化坐标，`seat` 是臀部承托边缘，手按画面左右且仅登记可见部位。查询返回registration；取用后回读本集manifest与 `registration_readback`，再试装当前景别和接触。字段与复制校验不批准姿态自然度。

需要部件独立动作时先看 `asset_bundle` 与装配说明。血糖仪/试纸、药瓶/瓶盖和主机/袖带分别保管原PNG、内容边界、接触点与朝向；储备批次中的人物、环境、器官、检查和照护部件也遵循同一拆分规则。MAC取用会分别登记部件。生成前先决定拆分，生成后查真实alpha及浅/深/彩底合成，再实际试装。伪棋盘、外围光晕、缺少被遮挡内容或无法独立操作时处理/重做后另存新版本，不把整图强称为分层。完整背景和医学整图只按明确整体用途复用。

公共库不保管作者专属资产。专用声线、医生形象、品牌参数与签名音乐留在私有作者工作区；公开同步跳过作者范围、品牌包和带品牌的样片。本机作者形象只在本机作者工作区使用，公共库提供通用中国男女医生；两者不能互相替代，其他用户只能发现通用医生。公开前查看所有附带媒体，不能只修改推荐开关。

看过候选后，按本集用途选择原件复用、局部适配、另找合法素材或 ImageGen 新创。无需满足复用数量、复用率或固定镜头数。没有合适素材或库不可用时记录诊断，继续故事与新创；不能为了复用把不合适纸件塞进画面。复用技法提供下限，代表镜头和整集的连续审片推动上限。

实际取用保留精确 ID、版本、来源与许可、真实文件及原审核范围；当前镜头的视觉、医学和听感重新审查。文件、哈希和入库不签发任何质量或发布批准。

交付后的精选新创可从工作台同步：`python3 tools/sync_from_workbench.py --workspace <目录> --root <本库>`。保存独立载荷、原记录与证据、适用/失败条件；被替代或不可复用版本按精确ID清理；先执行 `tools/verify_catalog.py`，再由模型审看复用价值。同步和推送属于明确写操作，查询不隐式更新库。

## 按对象、用途和动作发现

`query_assets.py --category 配乐 --query 探索 --json` 以中文别名发现情绪配乐；`--action 翻页 --story-role 记录随访` 按可执行动作与叙事用途筛选；`--collection door` 返回组合内精确原件。优先搜索名称、别名、标签与用途；需要追溯才启用 `--include-provenance`，避免来源文本污染物件搜索。标签欠项不限制标题发现，也不限制新创。

装配与事件集合见 `collections/assemblies.json`、`event-kits.json`；声音见 `audio.json`。通过库根本地HTTP服务打开 `tools/preview-engine/index.html` 看可拖动时间轴的实际组合小样，`audio.html` 分别试听BGM/拟音、分轨和变体。复制组合使用MAC的 `use-collection`，保留精确成员、成功导入与欠项，不把多个物件烘焙成新合图。

几何候选bounds不等于艺术通过，每个部件独立取bounds、接触点和遮挡职责。静态、组合、连续动作、医学、听感及当前镜头分别登记证据。医学外观与切面未经配准不能宣称剖开；音乐BPM与MIDI密度不替代完整试听。组合只提供动作下限，不固定构图、镜头、台词、时码或风格上限。
