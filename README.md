# MAC Media Assets · 医学科普纸剧场资产库

这是 [Med Auto Cast（MAC）](https://github.com/gaofeng21cn/med-autocast) 的公开媒体资产库。MAC 安装或准备工作台时自动获取，制作时按故事需要检索、查看并选择复用、适配或新创。

## 安装与使用

MAC 将本库声明为必需能力包；通过 OPL Framework 安装 MAC 时，Framework 一并安装素材库，
并通过 installed descriptor 提供检索与媒体路径。OPL App 的首次安装和显式恢复 Official
Profile 使用同一安装链；库本身不运行安装器、不保存账户或项目状态。

也可克隆本仓库，直接离线查询与验证：

```bash
git clone https://github.com/gaofeng21cn/mac-media-assets.git
cd mac-media-assets
python3 tools/query_assets.py --help
python3 tools/verify_catalog.py
```

原件位于 `payloads/`，登记与相对引用位于 `catalog/`、`records/` 和 `collections/`。
`records/` 内的历史工作台路径仅记录来源，不是可执行安装路径；消费者使用本次安装的根目录。

## 开发与验证

开发验证使用 Python 3.11、Pillow 和 Node.js 24。

```bash
uv run --with Pillow python -m unittest discover -s tests -v
python3 tools/verify_catalog.py
node tools/check_motion_studies.mjs
python3 tools/materialize_package.py --check
```

更新目录或载荷后运行 `python3 tools/materialize_package.py` 刷新 capability descriptor 的内容锁，
再运行以上检查。Package 发布由 Framework 的既有 `publish-package.yml` 选择准确版本、源码
提交和 OCI predecessor 后执行；本仓不维护第二套发布器或 latest 指针。

## 环境分层与动作下限

环境类素材都带分层契约。`action_capable` 表示独立可动层已登记、可以承担接触、遮挡、揭示或转运；`static_backdrop` 表示整幅环境板只作低注意力舞台层，需要独立动作的物件必须另取单件。MAC 可以用 `--layering` 直接筛出可承接动作的环境件，避免在一张烘焙了人物和家具的整图上做做不到的动作。

纸剧场动作库提供揭起、撕开、折叠、翻页、剪开、拉出、展开、缠绕、夹合、落纸和笔迹，以及推镜、横移、收镜与倾斜漂移，全部是时间的纯函数，可随机 seek。它稳定的是“纸能怎么动”，不决定故事、构图、物件数量或复用率；批量生产的下限来自动作库、可拆层环境与比例契约，上限留给每集导演。

## 新素材如何进入库存

`tools/ingest_generated.py` 负责登记 imagegen 生成的透明纸件：测量真实 alpha、记录内容 bounds、保存生成回执，并拒绝两类不可用结果——四角不透明（背景被烘焙进图，不能作为可动纸层）和外围半透明占比过高（光晕，会在彩底上显脏）。入库前仍需目视确认图像内容与登记项一致；工具只证明像素边界，不证明医学、艺术或当前镜头可用。

本轮据表达力审计补入的三件，都来自真实断点：卧姿纸件补上“床上动作做不出来”，指认姿态补上“人物只能站着”，空白厨房台面补上“生活物件无处安放”。三件都不是补数量，而是补已确认做不出来的动作。

2026-10-22 的全季审查确认，主要人物若临时用圆头、梯形身体和独立四肢拼装，即使局部动作再多也会显著降质。因此资产库新增 10 个完整人物：成年男性站/坐、青少年女性、儿童女性、老年男女、孕妇站/坐和男女医生站姿。儿童、老人、孕妇和医生使用真实年龄/角色比例；人物不得用成人缩放或改色冒充。

人物覆盖按“角色 × 姿态”管理：12类角色的49个基础姿态槽分别登记精确候选、锚点、原图标尺与推荐状态，实时结果见覆盖报告。静态行走姿态不代表完整步态，站坐中间姿态不代表完整过渡。作者专属形象、姿态、声线保管在私有工作区；启用 `default_for_clinician` 后，所有医生别名、`generic` 和旧公共医生 ID 均沿作者母版解析。公共通用中国男女医生供未启用该策略的工作区取用。

2026-10-23 构图返修纳管9件：8件完整人物及1件手/哑铃局部单元，保留生成回执、已有身份参考、可见边界与锚点，并通过真实查询、取用和素材清单回读。同一浅绿衫红裤男性可用 `--collection adult_man_green_red_postures` 发现；扶手椅两种状态与呼叫者可用 `--collection supported_patient_calling` 发现。两组均真实整组导入，仍不代表连续步态、坐立、状态转换或急救动作。上腹坐凳与扶手椅患者是不可拆整件，动态血压人物只表达已佩戴状态，握哑铃单元不作为完整人物。

2026-10-23 储备批次新增 22 个公共包：15 个完整人物姿态、5 个医学结构包和 2 张空场环境板；2026-10-24 又补入 5 个可拆烹饪部件，并完成组合取用与浏览器关键帧检查。所有包均已完成真实 query→use→manifest 回读；当前镜头、医学、连续动作和手机宽审看仍分别保留。

2026-10-24 已补齐四类连续动作：[完整样片与交互预览](tools/preview-engine/motion.html)覆盖双侧步态循环、坐下—坐定—起立、接近—轻扶起身—伴行—松手，以及三次切配—入锅—连续翻动—盛盘。四包均保存完整人物姿态或独立接触层、可编辑时间线、正常播放与换底/手机预览、绑定当前字节的审看记录；人物采用逐帧纸剧场表演。[取用与适用范围](docs/motion-studies.md)列出精确版本和实际导入证据。原有静态姿态仍按原审看范围使用。
