# 比例、接触与审核记录修复（2026-11-01）

本次检查确认两套动作包存在装配错误，均已退出取用入口：原坐站包由完整人物接触单元替代，烹饪包新增修订，统一餐盘与锅台视角及盛出落点。组合预览同时修复门框贴合、翻页轴、管口落盖、手纸交接、袋口遮挡、餐盘视角和食物复制问题。

## 为什么发生

原坐站包把人物与椅子分别定尺寸：人物按 `480 / 678` 缩放，椅子另取宽度 360，缺少共同身体标尺；坐面朝向与髋腿也不协调。旧审看记录却写入接触关系成立，语义检查漏掉了实际错误。

随后发现 `motion_package.freeze()` 将准备清单和技术渲染结果自动写成 `passed`，包括固定审看人、日期、静态换底和完整动作结论。检查的 53 套旧样片中，49 套使用这种批量记录结构，另外 4 套使用早期审看格式。49 是受不可靠记录机制影响的数量，不是画面错误数量。旧包保留原字节；当前有效结论由精确版本策展决定覆盖。

查询、组合浏览和导入原先分别读取目录/原记录，撤回决定可能因目录陈旧、精确 ID 或缓存入口而失效。现在查询、浏览器和 MAC 导入均读取中央策展，损坏的决定不会静默放行；目录另保留一致投影供兼容消费者读取。本工作台缓存的精确版本注解也已更新。

## 防止再次扩散

新动作冻结先核对真实渲染输入，再保存独立审看请求；缺少独立审看记录时只能登记 `pending`。`mac_motion_review/v2` 绑定输入和媒体、审看文件、观察及范围。完整动作通过还要求当前 MP4 与覆盖全时长的审看区间。机器验证这些声明与文件一致，具体质量仍由实际审看判断。

`collections/curation.json` 是当前精确版本决定；`tools/apply_curation.py` 投影目录，`--check` 检查漂移。默认查询、精确查询、组合和导入均拒绝撤回版本；只读追溯须显式 `--include-withdrawn`，其 `available_for_use` 为 false。同步不能恢复撤回版本或旧通过声明。

本地传播检索在 `productions/`、`content/`、`templates/` 的 JSON/JS/MJS/YAML 中未找到原坐站精确 ID 或原图 SHA；`work/` 的命中属于试装、审核或安装快照，保留作历史。该检索不等于逐集审看成片，也不据此声称既有视频全部合格。库修订不自动改旧工程。
